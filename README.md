# trabajo Practico N1
 ## Descripción 
 Este trabajo practico trabaja con archivos JSON y maneja operaciones asincronas mediante promesas

 ## Instalación 
 se utiliza "npm install" para leer el archivo "package.json" e instalar las dependendencias necesarias
 dentro de la carpeta "node_module".

 ## Ejcución
 Para ejecutar todo el programa se utiliza el comando "node index.js"

 ## Estructura del Proyecto

       |---- catalogo-juegos.txt

       |---- juegos.js

 ## Dependencias 
 el proyecto utiliza picocolors como dependencia y se instala a traves del comando "npm install picocolors".
